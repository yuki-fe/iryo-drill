医療事務用語ドリル医療事務の仕事と資格の勉強で使う用語を、無料で覚える単語帳

医療事務の仕事と、医療事務の資格の勉強で使う用語を、178語収録しています。医療保険のしくみ、公費負担医療と介護保険、診療報酬、レセプトと窓口の仕事、医学の基礎、カルテの略語、医療に関する法律まで、はじめて医療事務を学ぶ人にも分かるように、やさしい言葉で説明しています。登録は不要で、スマホでもパソコンでも無料で使えます。

学び方

カード
意味を読んで用語を思い出し、裏返して確かめます。「用語 → 意味」の向きにも切り替えられます。
4択クイズ
ア〜エの選択肢から答えを選びます。同じ分野の、まぎらわしい用語がひっかけとして並びます。
書いて答える
説明を読んで、用語を自分で入力します。「DPC/PDPS」のような略語は、そのまま入力して答えます。
復習
「まだ」を押した用語や、クイズで間違えた用語だけを集めて、学習し直せます。
ミニテスト
7つの分野から20問を出します。分野ごとの正答率がわかります。
略語クイズ
Rp・do・p.o.・BP・CRP など、カルテや検査の略語の正式名と意味を覚えます。

収録している分野

医療事務の仕事で使う知識を、7つの分野に分けています。特定の試験の範囲に合わせたものではありませんが、医療事務の資格の勉強にも使えます。診療報酬の点数は、改定（原則2年に1度）で変わるので、このサイトでは点数を書かずに、しくみと用語の意味を説明しています。

  • 医療保険のしくみ27語
  • 公費負担医療と介護保険14語

  • レセプトと窓口23語
  • 医学の基礎32語
  • カルテの略語36語
  • 法律と医療の仕事19語

すべての用語は用語一覧から、1語ずつ解説ページで読めます。
