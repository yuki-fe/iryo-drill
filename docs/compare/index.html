似た用語の違い医療事務でまぎらわしい用語 15組

医療事務の仕事では、名前や役割の似た制度・用語を正しく使い分けることが大切です。2つ（3つ以上）の用語を表で並べて、どこが違うかを確かめましょう。

  • 初診料と再診料・外来診療料の違い

    その病気で初めての診察なら初診料、同じ病気で2回目以降なら再診料です。大きな病院では、再診料の代わりに外来診療料になります。

  • 被用者保険・国民健康保険・後期高齢者医療制度の違い

    雇われて働く人とその家族は被用者保険、それ以外の人は国民健康保険、75歳以上の人は後期高齢者医療制度に入ります。レセプトの提出先も分かれます。

  • 協会けんぽ・組合健保・共済組合の違い

    どれも被用者保険です。中小企業の人は協会けんぽ、自分の健康保険組合がある会社の人は組合健保、公務員や私立学校の教職員は共済組合に入ります。

  • 被保険者と被扶養者の違い

    被保険者は自分が保険に入っている本人、被扶養者は本人に養われていて、本人の保険で医療を受ける家族です。被扶養者のしくみは被用者保険だけにあります。

  • 支払基金と国保連の違い

    どちらもレセプトを審査して支払う審査支払機関です。被用者保険（社保）のレセプトは支払基金、国民健康保険と後期高齢者医療制度のレセプトは国保連に出します。

  • 返戻・査定・再審査請求の違い

    返戻はレセプトが丸ごと戻ってくること、査定は戻らずに点数の一部が減らされること、再審査請求はその結果に納得できないときにもう一度審査を求めることです。

  • 出来高払い・包括払い・DPC/PDPS の違い

    出来高払いは行った医療を1つずつ足すしくみ、包括払いはまとめた金額で請求するしくみです。DPC/PDPS は、急性期の病院の入院で使われる包括払いの1つです。

  • 選定療養と評価療養の違い

    どちらも保険外併用療養費の対象です。選定療養は患者が快適さや便利さのために選ぶもの、評価療養は将来保険の対象にするかを評価している医療です。

  • 混合診療と保険外併用療養費の違い

    保険の医療と保険外の医療を一緒に行う混合診療は原則として認められず、行うと全部が自費になります。保険外併用療養費は、その例外として認められた場合に、保険の部分を保険から出すしくみです。

  • 高額療養費制度と限度額適用認定証の違い

    高額療養費制度は、1か月の自己負担が上限を超えた分が保険から出るしくみです。限度額適用認定証は、それを窓口で使い、最初から上限までの支払いにするための証明書です。

  • 労災保険と自賠責保険の違い

    労災保険は仕事中や通勤中の病気・けがを補償する保険、自賠責保険は自動車の事故の被害者を救うための保険です。どちらも、ふつうの健康保険とは扱いが違います。

  • 先発医薬品と後発医薬品の違い

    先発医薬品は新しく開発されて最初に発売された薬、後発医薬品（ジェネリック）は、その特許が切れたあとに同じ有効成分で作られた、安い薬です。

  • i.v.・i.m.・s.c.・DIV の違い（注射の略語）

    カルテで使われる注射の略語です。i.v. は静脈注射、i.m. は筋肉注射、s.c. は皮下注射、DIV は点滴静脈注射を表します。

  • X-P・CT・MRI・US の違い（画像の検査の略語）

    体の中を画像で見る検査の略語です。X-P と CT はエックス線を使い、MRI は磁石と電波、US は超音波を使います。

  • 医療法・医師法・健康保険法の違い

    医療法は病院・診療所などの医療機関の決まり、医師法は医師という人の決まり、健康保険法は健康保険のしくみの決まりです。
