労災保険と自賠責保険の違い

労災保険は仕事中や通勤中の病気・けがを補償する保険、自賠責保険は自動車の事故の被害者を救うための保険です。どちらも、ふつうの健康保険とは扱いが違います。

表で比べる

観点労災保険自賠責保険
対象仕事中・通勤中の病気やけが自動車の事故による人のけがや死亡
入る人働く人を雇っている事業主が、原則として入る自動車の持ち主が必ず入る
健康保険との関係仕事が原因のものは健康保険を使えない健康保険を使うこともでき、そのときは「第三者行為による傷病届」を出す
対象にならないもの仕事や通勤と関係のない病気やけが車などの物の損害

見分けるポイント

  • 「仕事中・通勤中」なら労災保険
  • 「交通事故」なら自賠責保険か、健康保険（届け出が必要）
  • 仕事中のけがを健康保険で受け付けると、あとで切り替えの手続きが必要になる

仕事での使われ方

受付では、けがの原因（仕事中か、交通事故か）を確かめて、どの保険で扱うかを決めます。原因によって書類やレセプトの扱いが変わるので、問診票や患者の話をよく確かめます。

それぞれの用語

  • 労災保険

    仕事中や通勤中の病気・けがを補償する保険。この場合は健康保険を使わず、労災保険で医療を受ける。

  • 自賠責保険

    交通事故の被害者を救うために、自動車の持ち主に入ることが義務づけられている保険。交通事故のけがの治療費に使われることがある。
